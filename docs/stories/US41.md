# #115 US41: Edit the Data-Cleaning Rules
Status on GitHub: OPEN

As an administrator, I want to change the data-cleaning limits without changing code so that I can respond to problems in new TLC data.
Depends on: US40
Estimate: 3 points
## Developer Tasks
- Move the limits now hard-coded in zones/importer/clean.py (maximum fare $500, distance 0 to 100 miles, duration 1 to 180 minutes) and zones/importer/rideshare/clean.py (its fare, distance, duration and wait limits) into one editable settings record per dataset, shown in the Django admin
- Start both records with today's values, so nothing changes until an admin edits them
- Validate: minimums below maximums, no negative values, and a maximum fare of at most $500 so fare reports (US24) keep matching
- Make both import commands read the current rules, and save the values used in ImportRun (US40)
- Record who changed a rule and when, and show it in the admin
- Changes apply at the next import; record this in docs/decisions.md, since it changes the US0a and US27 decisions
## Acceptance Criteria
- An admin can change any cleaning limit for taxi or rideshare data in the admin
- Invalid values (a minimum above its maximum, a negative value) are rejected with a clear message
- The next import uses the new limits, and its import history shows them
- With the starting values, both imports give exactly the same results as today
- Each change shows who made it and when
