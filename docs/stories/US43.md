# #117 US43: Manage Zone Adjacency
Status on GitHub: OPEN

As an administrator, I want to add or remove adjacent-zone pairs so that the cheaper-pickup suggestions and ride matching use sensible neighbours.
Depends on: US39, US18
Estimate: 3 points
## Developer Tasks
- Add a ZoneAdjacencyOverride model: two zones, action ("add" or "remove"), reason, who and when
- Combine zones/data/zone_neighbors.json with the overrides in one place (load_zone_neighbors() in zones/stats.py), so US19 (cheaper adjacent pickup) and US32 (ride matching) both use the result
- Always apply a pair both ways (if A borders B, B borders A); refuse a zone paired with itself
- Refresh the combined list when an override is saved or deleted, so changes apply straight away without a restart
- Show each zone's current neighbours in the admin, marking which come from the file and which from overrides
## Acceptance Criteria
- An admin can add a missing pair or remove a wrong one, with a reason
- The change applies both ways, and straight away, to cheaper-pickup suggestions and ride matching
- Deleting an override returns the pair to what the file says
- A zone cannot be paired with itself
- Rebuilding zone_neighbors.json with the US18 script keeps the overrides
