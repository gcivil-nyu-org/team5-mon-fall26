# #10 US8: View Trip Summary
Status on GitHub: OPEN

As a taxi-vs-rideshare decider, I want to see the fare range, trip duration, and best/worst travel windows together in one summary panel so that I can decide quickly.

Developer Tasks
- Build a summary panel component
- Combine fare range, trip duration, and best/worst windows in the panel
- Open the panel automatically when both zones are selected

Acceptance Criteria
- The panel opens when a pickup and destination zone are both selected
- It shows the fare range, trip duration, and best/worst windows in one place
- The panel updates when the zones or time filters change
- The user can close the panel and reopen it
