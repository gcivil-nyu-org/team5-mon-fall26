# US47 #121: Restrict an Account

As an administrator, I want to stop an account from posting or messaging without suspending it so that I can respond to a smaller problem proportionately.

Depends on: US46, US31, US36. Estimate: 2 points.

## Developer tasks

- Add a "Restrict" action with a required reason and an optional end date, and a "Lift restriction" action
- A restricted user can still sign in, browse and use their saved routes and plans, but cannot post a ride, show interest, send a message or submit a fare report
- Show a restricted user why, and until when, wherever those features are blocked
- Lift a restriction automatically once its end date has passed (checked when the user acts, so no scheduled job is needed)
- Record who restricted or lifted it, when, and why

## Acceptance criteria

- A restricted user can browse but cannot post, show interest, message or report a fare, and sees why
- A restriction with an end date stops applying after that date
- Lifting a restriction restores those features straight away
- Every restriction and lift records the admin, the time and the reason
