# #74 US27: Import Rideshare Trip Statistics (enabler)
Status on GitHub: OPEN

As the product team, we need historical Uber and Lyft trip statistics from the TLC High Volume For-Hire Vehicle data so that the app can compare taxi and rideshare fares.

Tier: Nice-to-Have · Depends on: US0a · Feeds US28 #75 (taxi vs. rideshare fares) and US29 #76 (surge overlay)

**Acceptance Criteria (whole story)**
- One or more months of High Volume FHV data import with one command
- The import report shows rows read, removed by each rule, and kept
- Running the same import twice creates no duplicate rows, and a failed import leaves the old data in place
- The statistics cover March to May 2026, the same months as the taxi data

The decisions (fare, wait, shared rides, storage, load) are in `docs/decisions.md`, "Rideshare import (US27 #74)".
