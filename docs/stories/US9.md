# #11 US9: Use Without an Account
Status on GitHub: OPEN

As a rider, I want to use the map and all trip information without creating an account so that I can get answers immediately.

Developer Tasks
- Keep all endpoints for this epic public, with no login required
- Make sure no sign-up prompt blocks the map or trip information.
- Test the full flow in a logged-out (private) browser window

Acceptance Criteria
- Every feature in this epic works without signing in.
- No sign-up or login prompt appears while exploring
- No personal data is collected while using these features
