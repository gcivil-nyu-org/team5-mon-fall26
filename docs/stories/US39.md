# #113 US39: Admin Access and Staff Accounts
Status on GitHub: OPEN

As an administrator, I want a staff-only admin area and a clear way to create admin accounts so that only the team can manage data and content.
Depends on: none
Estimate: 1 point
## Developer Tasks
- Keep the Django admin at /admin/ open to staff accounts only, and check that no other admin page or action can be reached by a non-staff user
- Show an "Admin" link in the site header for staff accounts only
- Document in the README how to create an admin account locally and on Integration and Production (for example createsuperuser through Elastic Beanstalk), and how to remove one
- Register Zone in the admin as read-only for now (US42 makes the names editable)
## Acceptance Criteria
- A staff account can sign in to /admin/
- A normal rider account cannot open any admin page, and gets the sign-in page or a 403
- The "Admin" link shows only for staff accounts
- The README explains how to create and remove an admin account on each environment
