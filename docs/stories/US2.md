# #4 US2: Select Trip Zones
Status on GitHub: OPEN

As a commuter, I want to select a pickup zone and an optional destination zone on the map so that I can see information for my specific trip.

Developer Tasks
- Add click handling to set the pickup zone, then the destination zone.
- Store the selected zones in the app state so other components can use them.
- Highlight the selected zones in distinct colors.
- Display the selected zone names and add a "Clear selection" option

Acceptance Criteria 
- The first click sets the pickup zone, and the second click sets the destination zone
- Pickup and destination zones are highlighted in different colors and named on screen
- The user can clear or change either selection
- The app works with only a pickup zone selected (destination is optional)
