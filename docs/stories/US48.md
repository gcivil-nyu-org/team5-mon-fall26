# US48 #122: Data-Quality Dashboard

As an administrator, I want a dashboard of data-quality numbers so that I can spot problems with a new import quickly.

Tier: Nice-to-Have. Depends on: US40, US44, US45. Estimate: 3 points.

## Developer tasks

- Add an admin-only page linked from the admin home, for taxi and rideshare data
- Show for the latest import: rows kept and removed by each rule, the share of cells below MIN_TRIP_COUNT, and zones with no trips
- Compare the latest import with the previous one, and highlight any rule whose removed share changed by more than 2 percentage points
- Show the number of fare reports held for review and open content reports, each linking to its admin list

## Acceptance criteria

- Only staff can open the dashboard
- Its numbers match the latest ImportRun records
- A change of more than 2 percentage points between imports is highlighted
- The held-report and open-report counts link to the right admin lists
