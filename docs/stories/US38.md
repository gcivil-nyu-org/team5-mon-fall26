# #101 US38: Report a Post or Message
Status on GitHub: OPEN

As a signed-in commuter, I want to report a post or message that is unsafe or inappropriate so that an admin can deal with it.

Depends on: US31, US36

### Developer Tasks

- Add a ContentReport model: reporter (on_delete=CASCADE), the reported post or message, reason (spam, unsafe, offensive or other), optional note (up to 300 characters), status (open or closed), created date
- Add a "Report" link on posts and on each message received; one report per user per item
- Register ContentReport in the Django admin with filters for reason and status, so admins can check reports until Epic 5 adds proper moderation
- Never show the reported user who reported them

### Acceptance Criteria

- A signed-in user can report a post or a message with a reason
- The same user cannot report the same item twice
- Reports appear in the Django admin with the reported content
- The reported user never sees who reported them
- A user cannot report their own post or message
