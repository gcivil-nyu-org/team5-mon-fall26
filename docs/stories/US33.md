# #95 US33: Show Interest in a Shared Ride
Status on GitHub: OPEN

As a signed-in commuter, I want to tell a post's owner that I'd like to share the ride so that we can arrange it.

Depends on: US32

### Developer Tasks
* Add a RideInterest model: post (on_delete=CASCADE), rider (on_delete=CASCADE), status (pending, accepted or declined), created date; one per rider per post
* Add an "I'm interested" button on each post and a "Withdraw" button once the rider has shown interest
* Block interest in the rider's own post, and in full, closed or expired posts
* Show the rider their own status on the post ("Pending", "Accepted" or "Declined")

### Acceptance Criteria
* A rider can show interest in an open post once, and can withdraw it
* A rider cannot show interest in their own post, or in a full, closed or expired post
* The rider sees the status of their interest on the post
* Deleting either account deletes the interest
