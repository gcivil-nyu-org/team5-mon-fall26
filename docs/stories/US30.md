# #92 US30: Choose a Display Name
Status on GitHub: OPEN

As a signed-in commuter, I want to choose a display name so that other riders see that name and never my email address.

Depends on: US12

### Developer Tasks
* Add a display name for each account (for example a small Profile model with user as a OneToOneField with on_delete=CASCADE, following docs/accounts.md)
* Add a "Display name" field to the "My account" page
* Validate: 3 to 30 characters, letters, numbers, spaces, dots, dashes and underscores; unique regardless of capitals; must not contain an email address
* Add a database constraint so names are unique ignoring capitals (a unique constraint on the lowercased name), so two people saving the same name at the same moment can’t both succeed
* Before a rider posts a ride, shows interest or sends a message, send them to set a display name first if they don't have one, then back to where they were
* Record the rules in docs/decisions.md

### Acceptance Criteria
* A signed-in user can set and change their display name on "My account"
* Two accounts can never have the same display name, even if the capitals differ (for example “Alex” and “alex”)
* A name that is too short, too long, has other characters, contains an email address, or is already taken is rejected with a clear message
* A user without a display name is asked to choose one before using any ride-sharing feature, then returns to what they were doing
* Deleting the account deletes the display name
* No Epic 4 page or response ever shows a rider's email address

The decisions are in `docs/decisions.md`, "Our choices (display name, US30 #92)".
