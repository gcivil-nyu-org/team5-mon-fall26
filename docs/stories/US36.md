# #98 US36: Message Riders About a Shared Ride
Status on GitHub: OPEN
Assignee: AleenaBoscoK

As a signed-in commuter, I want to message the post owner or a rider interested in my post so that we can agree on where and when to meet.

Depends on: US33

### Developer Tasks

- Add a RideMessage model: post (on_delete=CASCADE), sender, receiver (both on_delete=CASCADE), text (up to 500 characters), sent time, read time
- A conversation is between the post owner and one interested rider; only those two can read or post in it
- Add a conversation page with the messages oldest first and a send box; check for new messages every 15 seconds with a small JSON endpoint, plus on reload
- Show a reminder above the send box not to share addresses or phone numbers, and to meet in a public place
- Make the conversation read-only 24 hours after the ride's departure, or when the post is deleted
- Limit sending to 30 messages per user per hour to slow down spam
- Only check for new messages while the conversation page is visible on screen; pause when the tab is hidden and check again as soon as it is shown
- Record the polling and limits in docs/decisions.md and the High Level Design

### Acceptance Criteria

- The owner and an interested rider can send each other messages about a post
- Nobody else can open the conversation (they get 404)
- Empty and over-length messages are rejected
- New messages appear within 15 seconds without reloading the page
- After the time limit, the conversation is read-only
- No checks for new messages are made while the page is hidden in the background
- Deleting an account deletes the messages that user sent
