# #96 US34: Accept or Decline Interested Riders
Status on GitHub: OPEN
Assignee: matl114

As a signed-in commuter who posted a ride, I want to accept or decline riders who are interested so that I decide who shares my taxi.

Depends on: US33

### Developer Tasks

- On the owner's post page, list interested riders by display name with "Accept" and "Decline" buttons
- Accepting uses up a seat; when all seats are taken, the post becomes "Full" and stops appearing in search
- Allow the owner to undo an acceptance, which frees the seat and reopens a full post
- Accepted riders see "You're in" with the other accepted riders' display names
- Use one database transaction for accepting, so two quick accepts can't take more seats than offered

### Acceptance Criteria

- The owner sees every interested rider and can accept or decline each one
- Accepting the last free seat marks the post "Full" and hides it from search
- Undoing an acceptance frees the seat and makes the post open again
- A post never has more accepted riders than seats offered
- Riders see their updated status on the post
- Only the owner can accept or decline
