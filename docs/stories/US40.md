# #114 US40: Record and View Import History
Status on GitHub: OPEN

As an administrator, I want a record of every data import so that I can check what was loaded and how much was cleaned out.
Depends on: US39, US0a, US27
Estimate: 2 points
## Developer Tasks
- Add an ImportRun model: dataset (taxi or rideshare), months loaded, start and finish time, status (succeeded or failed), rows read, rows removed by each rule, rows kept, zone and route cell counts, cells with fewer than MIN_TRIP_COUNT trips, the cleaning limits used, and the error message for a failed run
- Make import_trips and import_rideshare save one ImportRun from the report they already print, including failed runs
- Show the history in the Django admin, newest first, filterable by dataset and status, read-only (no add, edit or delete)
## Acceptance Criteria
- Every taxi and rideshare import, successful or failed, creates one record
- The record's numbers match the report printed by the command
- A failed import records its error message
- Admins can view and filter the history but cannot change it
