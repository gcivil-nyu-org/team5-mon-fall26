# #116 US42: Manage Zone Names and Boroughs
Status on GitHub: OPEN

As an administrator, I want to correct zone names and boroughs so that the map and every page show clear, correct labels.
Depends on: US39
Estimate: 2 points
## Developer Tasks
- Make Zone editable in the Django admin: name and borough only; zone_id read-only; no adding or deleting zones (deleting would delete their statistics, plans and posts)
- Add a search by name and a filter by borough
- Stop the import from undoing admin edits: upsert_zones in zones/importer/load.py currently overwrites name and borough on every run. Add an "edited by admin" flag that the import skips, and show it in the admin
- Record who last edited a zone and when
## Acceptance Criteria
- An admin can change a zone's name or borough, and the change shows on the map, the compare page, plans and ride posts after a reload
- Running import_trips again does not undo an admin's edit
- Zones cannot be added or deleted from the admin
- The zone list shows which zones were edited, by whom and when
