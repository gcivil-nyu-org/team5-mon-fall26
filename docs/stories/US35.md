# #97 US35: Edit, Close, or Delete My Post
Status on GitHub: OPEN
Assignee: matl114

As a signed-in commuter, I want to edit or close my post, or delete it, so that it stays accurate once plans change or I've found someone.

Depends on: US31, US34

### Developer Tasks

- Allow the owner to edit the departure time, seats and note of an open post, with the same validation as US31; seats can't go below the number of accepted riders
- Add "Close post" (no new riders; accepted riders keep access) and "Delete post" (asks for confirmation)
- Show interested and accepted riders that a post was closed or deleted, in their "My rides" list (US37)
- Return 404 if anyone other than the owner tries to edit, close or delete a post

### Acceptance Criteria

- The owner can edit an open post, with the same rules as when posting
- Seats can't be set lower than the riders already accepted
- A closed post disappears from search but stays visible to the owner and accepted riders
- A deleted post is removed for everyone, and interested riders see that it was deleted
- Only the owner can edit, close or delete the post
